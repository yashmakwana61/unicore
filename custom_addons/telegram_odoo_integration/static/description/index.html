Telegram Odoo Integration

Create Sales Orders automatically from Telegram bot messages.

Features

✔ Public JSON webhook POST /telegram/webhook
✔ Configurable bot token and allowed chat id (Settings > Telegram)
✔ Automatic customer & product creation
✔ Multiple products per message
✔ Telegram chat history stored in Odoo
✔ Reply to users through the Telegram Bot API

Usage

Send an order to the bot in this format:

Order: Laptop Qty:2 Price:50000

Multiple products (comma separated):

Order: Laptop Qty:1 Price:50000, Mouse Qty:2 Price:300

The bot replies Order created successfully: SO00001.

Compatibility

Odoo 16 / 17 Community Edition (also runs on newer versions).
