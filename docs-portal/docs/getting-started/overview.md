# Welcome to Edicai

Edicai is an education management platform developed by **Precisefect Solutions Pvt. Ltd.**, built on Odoo 19 Community Edition.

The repository includes student records, admissions, academics, attendance, finance, learning, campus management, analytics and portals.

## Verified administrator training

For a screenshot-backed walkthrough of institution setup, company settings, roles, academic years, semesters, campuses, faculties, departments, and programs, see the [Administrator Training Guide](../training/README.md). The separate Home **Getting Started** checklist is optional demo/onboarding functionality.

## First steps

1. Browse the [module catalog](../reference/module-catalog.md).
2. Explore the [institution workspace](../workspaces/workspace-1.md) or [admissions workspace](../workspaces/workspace-2.md).
3. Check [installation guidance](./installation.md) before working with a new environment.

:::caution Evidence policy
Module presence in source code is not confirmation that it is installed, enabled or working in a particular institution's database. All operational procedures require verification.
:::
