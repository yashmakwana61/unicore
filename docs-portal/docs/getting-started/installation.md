# Installation and Validation

Use the repository's [deployment instructions](https://github.com/yashmakwana61/unicore/blob/main/DEPLOY.md) and Docker configuration as the initial technical references.

## Controlled verification

1. Select a reviewed Git revision and provision an isolated Odoo 19 staging environment.
2. Use synthetic data; never copy real student or financial records into public screenshots.
3. Resolve module dependencies and install the intended feature set.
4. Verify menus, roles, actions, reports and student workflows.
5. Record the installed module versions and publish only approved operational steps.

:::warning Not a production deployment runbook
The steps above are preparatory. Exact deployment commands require verification against the target infrastructure.
:::
