# Academic and institution setup

> **Documentation status:** This section contains source-reviewed background. The separate [Administrator Training Guide](../training/overview.md) contains 38 UAT screenshots and tested setup steps for a university-style environment; untested institution variants still require verification.

Edicai supports multiple educational institution types rather than requiring every organization to use a university structure.

## Functional building blocks

- **Institution Profiles:** university, college, K-12 school, training institute, academy/test preparation and coaching center.
- **Academic Structure:** faculties, departments, programs and specialisations.
- **Flexible Academic Units:** academic unit types and generic organization hierarchy.
- **Institution settings:** calendars, terminology profiles and grading schemes.
- **Program cohorts:** academic-year, grade-level and rolling-intake groupings.

The base menus include **Edicai → Academic Structure** and configuration menus for **Institution Profiles**, **Terminology Profiles**, and **Grading Schemes**. Navigation visibility depends on access and active overrides.
