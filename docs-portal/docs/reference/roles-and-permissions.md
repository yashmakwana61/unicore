# Roles and Permissions

The source defines administrative and institutional security groups and uses Odoo ACLs and record rules.

Role terminology includes administrator, registrar, staff, faculty, finance, manager and student. Effective permissions must be tested in the target database, including inherited groups and record rules.

Review the [existing navigation role matrix](https://github.com/yashmakwana61/unicore/blob/main/docs/navigation_audit/role_navigation_matrix.csv) as a planning artifact; it is not proof of authorization.
