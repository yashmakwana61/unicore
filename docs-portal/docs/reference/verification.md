# Publication and Verification

## Evidence levels

- **Source-confirmed:** manifest name, dependencies, and module metadata verified in the repository.
- **Design proposal:** navigation and workflow layouts that may not be active.
- **Runtime-verified:** confirmed in a disposable Odoo environment by a test user of the intended role.
- **Approved:** reviewed for correctness, privacy, accessibility and consistency.

No screenshot-led user guide should be published until validated. Machine-generated references do not establish installed status or guarantee functional correctness.
